Review and report

Import auto-validates and unlocks Generate Net (GJ/a) when SOC is present. Use top-bar Validate / Export after edits. Official house reports for permits must come from HOT2000 Desktop.

  1. 1

    Validation status & export options

    Import auto-validates. After Envelope/Systems edits, click top-bar Validate again. Export unlocks when validation passes (even if SOC is missing). Generate Net (GJ/a) unlocks only when validation passes and SOC is present.

    Click top-bar Validate to check this house file and enable Export.
  2. 2

    Net GJ/a — standard operating conditions

    Enabled after validation passes and SOC results are present (including after Import). Disabled again if you change Envelope or Systems until Validate passes. This is not a permit report.

    Import a calculated .h2k with SOC, or Validate when SOC is present, then generate Net GJ/a.

    Permit / submission house report

    Use HOT2000 Desktop only. Authorities expect the exact Full House Report wording and format from HOT2000:

    1. Use top-bar Export if SOC is missing, then calculate in HOT2000 Desktop.
    2. Choose Report → Full house report → House with standard operating conditions.
    3. Print / Save that Desktop PDF for the permit package.

    This web editor cannot produce a permit-accepted house report. Do not submit any web-generated PDF in place of the HOT2000 Desktop report.

Model inventory

Recommended flow

  1. Import a calculated .h2k — auto-validates; Generate Net (GJ/a) enables if SOC is found.
  2. Edit House / Envelope / Systems as needed.
  3. After Envelope or Systems changes, top-bar Validate again (Generate stays off until then).
  4. If SOC is missing, Export and calculate in HOT2000 Desktop, then re-import.
  5. For permits, print the official Full House Report from HOT2000 Desktop.
