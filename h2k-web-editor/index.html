How Net GJ/a is produced

  1. Build and edit the house file here (House → Envelope → Systems).
  2. Validate with no blocking errors.
  3. Export .h2k and recalculate in HOT2000 Desktop if SOC results are missing or stale, then re-import.
  4. When SOC is present, Generate Net GJ/a.
  5. After generation, download the PDF house report for standard operating conditions.
